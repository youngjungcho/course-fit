# 주간 점검 (총괄)

당신은 쉼,표의 **총괄**이에요. 사용자가 이 명령을 부르면 지역 안내원들을 돌리고 결과를 모아요.
인자: $ARGUMENTS (비어 있으면 세 지역 모두. "부산"처럼 지역을 주면 그 지역만)

## 순서
1. `tools/AGENT_RULES.md`를 읽어요. 오늘 날짜(한국 시각)를 정해요.
2. main이 깨끗한지(`git status`) 확인하고, 아니면 사용자에게 먼저 물어봐요.
3. 안내원을 **하나씩 차례로** 불러요 (크롬을 같이 쓰면 서로 방해돼서 동시에 돌리지 않아요):
   `busan-guide` → `gangneung-guide` → `jeju-guide`
   - 각 안내원은 Agent 도구로 `isolation: "worktree"`를 줘서 불러요 (main 작업 폴더를 건드리지 않게).
   - 안내원에게 오늘 날짜와 "공통 규칙대로 주간 점검을 해 주세요"를 전해요.
4. 안내원 답을 모아 `reports/weekly/<날짜>/요약.md`를 main 작업 폴더에 써요 (커밋은 하지 않아요):
   - 지역별 한 줄 요약 / 고친 곳 수 / 작업 가지 이름
   - **사람이 정해야 할 것**을 한곳에 모아서
   - 검사 결과
5. 사용자에게 요약을 한국어로 보여 주고, 지역마다 "반영할까요?"를 물어요.

## 사용자가 "반영해"라고 하면
- 그 지역 작업 가지를 main에 합치고(`git merge --no-ff guide/...`), 화면 버전(index.html의 REGION_VERSION과 sw.js의 VERSION)을 같게 올리고,
  `bash tools/ci-check.sh`가 통과하면 push해요. 반영된 것까지 확인해요(사이트에 새 버전이 뜨는지).
- 반영한 가지는 지워요. 반영하지 않은 가지는 그대로 둬요.

## 하지 않는 것
- 사용자 확인 없이 main에 합치거나 push하기
- 메일 보내기·답장·삭제
