# 이번 주 인스타 카드뉴스

인자: $ARGUMENTS (비어 있으면 2개를 알아서 골라요. "경주 아기랑"처럼 주면 그 주제로 1개)

## 순서
1. `marketing/insta/log.md`를 읽어요. 최근 8주에 만든 지역·동행 조합은 피해요.
2. 주제 고르기 (인자가 없으면 2개):
   - 지역(애월·한림·제주시내·서귀포·함덕·성산·한경·남원·강릉·부산·경주)과 누구랑(group·dog·kid·wheel·solo), 어떻게(walk·bike·car)를 섞어요.
   - 계절을 봐요: 여름엔 바다·실내, 겨울엔 실내·온실·시장, 비 많은 철엔 실내 위주.
   - 강릉·경주는 버스 자료가 없어서 walk 대신 car·bike.
   - 형식도 돌려 가며 골라요. 매번 코스 카드만 올리면 비슷해 보여요.
     · 코스 카드: `make.js` (아래 3~4번)
     · 같은 곳, 다른 사람: `node marketing/insta/compare.js <지역> <how> <출발지 id>` 로 강아지·아기·휠체어·혼자 코스를 나란히 보여 줘요.
       네 코스가 모두 나오고 서로 많이 다른 출발지를 골라요(전부 비슷하면 다른 출발지로). 멘트에 "📌 이런 게 달라져요"를 자료에 있는 사실로만 더해요.
3. 후보 보기: `LIST=1 node marketing/insta/make.js <지역> <who> <how> 10:00 6`
   - 그 지역 대표 명소가 들어가고, 밥때 식당이 있고, 동선이 자연스러운 코스를 골라요.
4. 만들기: `ALT=<번호> node marketing/insta/make.js <지역> <who> <how> 10:00 6 "" <출발지 id>`
5. 확인: 만든 PNG를 하나씩 열어 봐요(Read). 글자가 잘리거나 겹치면 make.js를 고치고 다시 만들어요.
   - 쉬는 날·운영시간 확인 필요 배지가 많은 코스는 피해요.
   - 사실이 아닌 말(후기·별점·"인기 1위" 같은 말)을 넣지 않아요.
6. `caption.txt`(게시글 멘트)를 읽고 어색한 곳만 다듬어요.
   - 구성: 첫 줄 후킹 → 짧은 소개 → 코스(시간·한 줄 설명) → 📌 알아 두면 좋아요(마지막 주문·반려견 조건·유아의자·버스) → 확인 안내 → 프로필 링크 → 해시태그 5개 (인스타가 게시물당 5개까지만 받아요: 지역 2·누구랑 1·어떻게 1·여행코스추천)
   - 첫 줄은 그 주제에 맞게 더 끌리게 바꿔도 돼요. 단, 자료에 없는 사실(맛집 1위, 웨이팅 등)은 쓰지 않아요.
   - 장소 계정 @태그는 공식 계정이 확인될 때만 넣어요.
7. `marketing/insta/log.md`에 한 줄씩 더해요.
8. 사용자에게 PNG와 본문 글을 보내요(SendUserFile). 한국어로 짧게: 무엇을 만들었는지, 올리기 좋은 때(평일 저녁 8~10시, 주말 오전).

## 하지 않는 것
- 인스타에 직접 올리기, 다른 계정에 메시지 보내기 (올리는 건 사용자가 해요)
- 커밋 (사용자가 말할 때만)
